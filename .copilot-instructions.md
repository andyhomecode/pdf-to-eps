# Copilot Instructions

## Project Context
This project appears to be focused on PDF to EPS (Encapsulated PostScript) conversion.

It is to be run under CUPSD on an Ubuntu linux server to share a Epson TM-T20II receipt printer over AirPrint.  Since AirPrint only supports PDF, and the Epson printer only supports EPS, this project converts PDF files to EPS files for printing.  it adds the Epson specific commands to control the printer for things such as cutting the paper after printing a receipt, and wraps lines.  

It has a test interface to be able to run it outcside of CUPSD for testing and development.  Feed in a PDF, get out an EPS.
